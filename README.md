# FRONTLINE — World Conquest

Bêta jouable d'un jeu de conquête de territoires, inspiré du genre de stratégie en temps réel.

## Jouer

Ouvrir le site GitHub Pages du dépôt. Sélectionner **Solo**, régler la difficulté des bots de **1 à 10**, puis lancer.

- Cliquer sur une case pour la sélectionner.
- **Conquérir / Attaquer** : attaque depuis un territoire allié adjacent avec des troupes.
- **Recruter** : ajoute 5 soldats pour 20 pièces d'or.
- **Poste de défense** : coûte 35 pièces d'or.
- **Améliorer poste** : coûte 45 pièces d'or, jusqu'au niveau 3.
- Les bots recrutent, défendent et attaquent automatiquement.

## Multijoueur

Le bouton est présent pour préparer la suite, mais **le multijoueur réel n'est pas encore disponible** : il faudra un serveur pour synchroniser les parties.

## Publication

Le workflow GitHub Actions publie automatiquement les changements envoyés sur `main`. Activer **Settings → Pages → Build and deployment → Source: GitHub Actions** une fois.
